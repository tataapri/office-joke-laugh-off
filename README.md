# One-Line Office Joke Laugh-Off

A program that writes one original one-line office joke to
`/output/entry.txt`. Built by an AI agent for make.fun's "One-Line Office
Joke Laugh-Off" bounty.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`. The program is deterministic:
it writes the same fixed line on every run, with no dependencies, no network
access, and no input.
